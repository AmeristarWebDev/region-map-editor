US Map Editor

Publish to GitHub

Use a fine-grained token scoped to this repo with Contents: Read and write. Publishing commits the map to the repo; GitHub Pages redeploys in about a minute.

Map

Key

Click a group to make it the active brush, then click states on the map to add or remove them. Or type abbreviations (e.g. TX, OK, ar) into a group. A state can only belong to one group. Drag region names on the map to reposition them.

Pins

Click “Add pin”, then click the map to place it. Drag pins to move them. Use a star for HQ and dots for offices.
